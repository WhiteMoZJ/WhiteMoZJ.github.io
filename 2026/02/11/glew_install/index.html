GLEW安装——使用MSYS+Mingw64

发表于2026-02-11|更新于2026-02-11|计算机图形学
|总字数:204|阅读时长:1分钟|浏览量:|评论数:

使用 MSYS+Mingw64 安装 gcc

  1. 打开 MSYS 官网：https://www.msys2.org/
  2. 下载安装 MSYS
  3. 运行 mingw64.exe
  4. 在窗口内输入指令
  5. 将 path/msys64 和 path/msys64/mingw64/bin 添加到环境变量(path 是你安装 MSYS 的路径)

安装 GLEW

  1. 下载 GLEW 源码：https://github.com/nigels-com/glew/releases/download/glew-2.3.1/glew-2.3.1.zip
  2. 解压，然后在文件夹下打开命令窗口
  3. 使用 Mingw64 编译 此处参考 GLEW 官方给出的安装教程，此方法更为简洁
  4. 将 include 和 lib 文件夹复制放入项目的文件夹下，使用 make/CMake 引用

Reference

[1] nigels-com. GLEW - The OpenGL Extension Wrangler Library[EB/OL]. [2026-01-24]. https://github.com/nigels-com/glew

[2] MSYS. Getting Started[EB/OL]. https://www.msys2.org/
