基于CMake 4.2.3 并使用 Windows + MinGW

添加 CMake 脚本

CMake 脚本的名称为 CMakelists.txt，在一个使用 CMake 的项目中，主目录和所有包含源代码的子目录都需要包含一个 CMakelists.txt 文件

初始化

并且每个 CMakelists.txt 文件都必须至少包含以下内容：

  • cmake_minimum_required(VERSION <cmake_version>) 用于规定 CMake 所需的最低版本, VERSION 是 CMake 内置的变量
  • project(<project_name>) 为项目规定名称，它也包含以下几个可选参数
    • VERSION <version>：为项目规定版本
    • LANGUAGES <language>: 可以是 C、CXX(C++)、JAVA、CUDA… 但需参考具体版本来查看对不同语言的支持
